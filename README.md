Nombre del proyecto: #Triple Espresso
Descripción del proyecto: sitio web para una cafetería, la cual te permite conocer cobre ella, te proporciona una sección de recetas, te permite hacer una reservación al establecimiento y tiene enlace a las redes sociales.
Autor: Fernando Hernandez Barrios.
Tecnologías utilizadas: HTML5, CSS, metodología BEM.
Planes de mejora del proyecto: modificar el estilo de la página, hacerla más interactiva, agragar música de fondo que suene mientras se mira la página.
